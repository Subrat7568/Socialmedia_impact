# Social Media Impact on Student Life — Dashboard

Interactive dashboard analyzing the relationship between social media usage, sleep duration, and sleep quality among 4,500 students.

## Features
- KPI cards: avg daily usage, sleep duration, sleep quality
- Filters: Academic Level, Platform, Device, Gender
- Charts: usage vs sleep (bucket + scatter), platform share, quality distribution, usage by age/device
- Live correlation insight that updates with filters

## Tech
- Pure HTML/CSS/JS, no backend required
- [Chart.js](https://www.chartjs.org/) via CDN

## Run locally
Just open `index.html` in a browser.
